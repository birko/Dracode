# Web UI improvements

> Stakeholder-readable. A PM/stocktaker should understand the problem and shape without code.

## Problem

The web interface used space inefficiently, making it harder to see everything at a glance. Project configuration was tangled into other screens, and when reloading a conversation the view cluttered itself with empty placeholder messages.

## Proposed shape

Tighten up the interface into a more compact, space-efficient layout so more information fits on screen. Give project configuration its own dedicated view instead of sharing space with unrelated controls. When a conversation reloads, show only the messages that actually have content, removing empty noise. The result is a cleaner, more focused experience.

## Out of scope (initial)

- Full visual redesign or rebranding
- Mobile-specific layouts
