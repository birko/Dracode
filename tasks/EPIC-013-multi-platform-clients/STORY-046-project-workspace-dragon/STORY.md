# Web UI: project workspace with Dragon docked

## User story

As a KoboldLair user, I want one workspace per project with Dragon beside it, so that I can watch the work and talk to Dragon without switching screens.

## Behaviour

- Workspace tabs in the centre, the read-only spec as the first (D11, D19)
- Dragon docked on the right, following the selected project (D11, D12)
- Dragon widens while it has focus and narrows when focus leaves (D13)
