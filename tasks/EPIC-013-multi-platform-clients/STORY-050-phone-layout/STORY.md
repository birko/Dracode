# Web UI: phone check-and-respond layout

## User story

As a KoboldLair user away from my desk, I want to check progress and answer Dragon on my phone, so that work does not wait for me to get back.

## Behaviour

- Phones: projects and progress, a read-only board, Dragon chat and decisions, notifications (D21)
- A bottom tab bar with Dragon as its own tab; tablets keep the desktop layout with Dragon as an overlay (D22)
