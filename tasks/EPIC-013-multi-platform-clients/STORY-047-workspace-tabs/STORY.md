# Web UI: workspace tabs — board, runs, git, stats

## User story

As a KoboldLair user, I want to see a project's tasks, runs, branches and numbers in its workspace, so that I can follow the pipeline from task to merge.

## Behaviour

- Board: status kanban, priority lanes in To do, Retry on failed cards (D16)
- Runs: the project's runs and a live run view (D7, D20)
- Git: branch diff and merge (D20)
- Stats: per-project numbers (D18)
