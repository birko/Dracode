# Questions climb the agent hierarchy

## User story

As a person using KoboldLair, I want an agent that cannot decide something to ask the agent above it, and only what nobody on the way can answer to reach me, in short rounds with a recommended answer, so that I decide what only I can decide and can see every answer the agents gave.
