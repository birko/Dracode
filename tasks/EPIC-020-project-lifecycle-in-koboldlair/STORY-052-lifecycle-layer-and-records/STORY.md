# Lifecycle layer and records

## User story

As a person using KoboldLair, I want each project to carry the same written record DraCode keeps for itself — its plan as epics, stories and tasks, the decisions I made, its conventions and a changelog — so that I can come back weeks later and see what was decided and how far it got.
